TipObjetivos del capítulo

Ya tenemos la pieza que faltaba: sabemos cómo varía un estadístico de muestra a muestra (Capítulo 7). Con eso podemos, por fin, responder las dos preguntas centrales de la inferencia: ¿cuánto vale el parámetro? (estimación) y ¿es compatible con cierto valor? (prueba de hipótesis).

8.1 Estimación puntual

La estimación puntual es lo más simple: usar el estadístico de la muestra como estimación del parámetro. Si la media de nuestras lagartijas urbanas es 35.4 °C, esa es nuestra estimación puntual de \(\mu\).

lagartijas <- read.csv("datos/lagartijas.csv")
urbanas <- filter(lagartijas, habitat == "urbana")
mean(urbanas$temp_corporal)
#> [1] 35.41875

El problema es evidente: un número solo, sin más, no comunica incertidumbre. Otra muestra habría dado otro valor. Necesitamos acompañarlo de un margen.

8.2 Intervalos de confianza

Un intervalo de confianza es un rango de valores plausibles para el parámetro, construido de modo que el procedimiento acierte un porcentaje conocido de las veces. Para una media, con \(\sigma\) desconocida (el caso real), es

\[\bar{x} \pm t^* \cdot \frac{s}{\sqrt{n}}\]

donde \(s/\sqrt{n}\) es el error estándar que ya conocemos y \(t^*\) es un valor crítico de la distribución \(t\) de Student, que depende del nivel de confianza y de los grados de libertad (\(n-1\)). Usamos \(t\) en lugar de la normal porque estamos estimando \(\sigma\) con \(s\), y eso agrega incertidumbre.

En R, t.test() lo calcula:

t.test(urbanas$temp_corporal, conf.level = 0.95)$conf.int
#> [1] 34.82984 36.00766
#> attr(,"conf.level")
#> [1] 0.95
ImportanteQué significa (y qué NO significa) el 95 %

La interpretación correcta es sobre el procedimiento: si repitiéramos el estudio muchas veces y construyéramos un intervalo cada vez, alrededor del 95 % de esos intervalos contendrían el verdadero \(\mu\).

Es incorrecto decir “hay 95 % de probabilidad de que \(\mu\) esté en este intervalo”. Una vez calculado, este intervalo concreto o contiene a \(\mu\) o no lo contiene (no hay azar ya); lo que tiene una tasa de éxito del 95 % es el método que lo produjo. El laboratorio siguiente vuelve tangible esta distinción.

8.2.1 Laboratorio: ¿qué significa “95 % de confianza”?

Cada línea horizontal es un intervalo construido a partir de una muestra distinta de la misma población, cuya media verdadera conocemos (la línea roja, \(\mu = 100\)). Los intervalos que no alcanzan a cubrirla aparecen en rojo. Los controles permiten cambiar el nivel de confianza y el tamaño de muestra.

viewof nivel = Inputs.select([90, 95, 99], {value: 95, label: "nivel de confianza (%)"})
viewof nIC = Inputs.range([5, 100], {value: 25, step: 5, label: "tamaño de muestra n"})
viewof semilla = Inputs.button("Nuevas muestras")
tcrit = ({90: 1.645, 95: 1.96, 99: 2.576})[nivel]
intervalos = {
  semilla;                       // al presionar el botón se regeneran
  const normal = d3.randomNormal(100, 15);
  return Array.from({length: 60}, (_, k) => {
    const x = Array.from({length: nIC}, normal);
    const m = d3.mean(x), s = d3.deviation(x);
    const e = tcrit * s / Math.sqrt(nIC);
    return { k, bajo: m - e, alto: m + e, media: m, cubre: (m - e) <= 100 && 100 <= (m + e) };
  });
}
Plot.plot({
  height: 300,
  marginLeft: 30,
  x: { label: "valor del parámetro", domain: [85, 115] },
  y: { axis: null },
  color: { legend: false },
  marks: [
    Plot.ruleY(intervalos, {
      y: "k", x1: "bajo", x2: "alto",
      stroke: d => d.cubre ? "#1F4E79" : "#C0392B", strokeWidth: 1.8
    }),
    Plot.dot(intervalos, { y: "k", x: "media", r: 2,
      fill: d => d.cubre ? "#1F4E79" : "#C0392B" }),
    Plot.ruleX([100], { stroke: "#C0392B", strokeWidth: 2 })
  ]
})
md`De estos **60** intervalos, **${intervalos.filter(d => d.cubre).length}** contienen el valor verdadero (µ = 100). Nivel nominal: **${nivel} %** → esperaríamos alrededor de **${Math.round(60 * nivel / 100)}**.`
NotaInterpretación

Conviene observar tres cosas. Primero, algunos intervalos fallan, y eso es normal, no un error: con 95 % de confianza, uno de cada veinte no cubre el parámetro. Segundo, al subir el nivel a 99 % los intervalos se ensanchan y fallan menos: más confianza cuesta menos precisión. Tercero, al aumentar \(n\) todos se angostan, porque el error estándar \(s/\sqrt{n}\) encoge.

Y lo esencial: el “95 %” describe cuántas veces acierta el método a la larga, no la probabilidad de que un intervalo particular contenga a \(\mu\).

8.3 La lógica de la prueba de hipótesis

Una prueba de hipótesis responde a una pregunta distinta: ¿los datos son compatibles con cierta afirmación? Su razonamiento es el de una reducción al absurdo probabilística, en cuatro pasos:

  1. Se plantea una hipótesis nula \(H_0\): la afirmación de “no hay efecto”, “no hay diferencia”, el statu quo. Y una alternativa \(H_1\), lo que sospechamos.
  2. Se supone que \(H_0\) es cierta y se calcula, bajo ese supuesto, la distribución del estadístico.
  3. Se mide qué tan raro sería observar unos datos como los nuestros (o más extremos) si \(H_0\) fuera cierta. Esa probabilidad es el valor p.
  4. Se decide: si el valor p es muy pequeño, los datos son poco compatibles con \(H_0\) y la rechazamos; si no, no hay evidencia suficiente para rechazarla.
ImportanteDos precisiones de lenguaje que importan

No decimos “aceptamos \(H_0\)”, sino “no la rechazamos”: la ausencia de evidencia no es evidencia de ausencia. Un valor p grande puede significar que no hay efecto… o que la muestra fue demasiado pequeña para detectarlo.

Y el nivel de significancia \(\alpha\) (típicamente 0.05) es un umbral convencional, no una ley de la naturaleza. Un p de 0.049 y uno de 0.051 dicen prácticamente lo mismo.

8.4 Hipótesis de una y de dos colas

La forma de \(H_1\) depende de la pregunta, y hay que fijarla antes de ver los datos:

Pregunta \(H_1\) Tipo de prueba
¿El parámetro difiere del valor de referencia? \(\mu \neq \mu_0\) Dos colas (bilateral)
¿Es mayor que el valor de referencia? \(\mu > \mu_0\) Una cola (unilateral derecha)
¿Es menor que el valor de referencia? \(\mu < \mu_0\) Una cola (unilateral izquierda)

La diferencia práctica es dónde se mide la rareza de los datos. En una prueba bilateral cuentan como “extremos” los resultados alejados en cualquiera de las dos direcciones, así que el valor p suma las dos colas; en una unilateral solo cuenta la dirección de interés.

En R se indica con el argumento alternative:

t.test(x, mu = 34)                            # bilateral (por omisión)
t.test(x, mu = 34, alternative = "greater")   # H1: mu > 34
t.test(x, mu = 34, alternative = "less")      # H1: mu < 34
ImportanteLa regla de oro de las pruebas unilaterales

La dirección de \(H_1\) debe surgir de la pregunta de investigación, nunca de haber mirado los datos. Elegir la cola después de ver hacia dónde apuntan los resultados es una forma de p-hacking: duplica artificialmente la evidencia aparente, porque un valor p bilateral de 0.08 se convierte en 0.04 unilateral con solo cambiar la hipótesis a posteriori.

Regla útil: si la pregunta es “¿mejoró?”, “¿es menor que?”, “¿superó el estándar?”, la prueba es unilateral. Si es “¿son distintos?”, es bilateral.

8.5 Los dos tipos de error

Toda decisión estadística puede equivocarse, y hay dos formas distintas de hacerlo:

\(H_0\) es cierta \(H_0\) es falsa
Se rechaza \(H_0\) Error tipo I (probabilidad \(\alpha\)) Decisión correcta (probabilidad \(1-\beta\))
No se rechaza \(H_0\) Decisión correcta Error tipo II (probabilidad \(\beta\))
  • El error tipo I es un falso positivo: declarar un efecto que no existe. Su probabilidad es exactamente el nivel de significancia \(\alpha\) que elegimos, típicamente 0.05.
  • El error tipo II es un falso negativo: no detectar un efecto que sí existe. Su probabilidad se denota \(\beta\) y no la fijamos directamente. Depende del tamaño real del efecto, de la variabilidad y del tamaño de muestra.
  • La potencia de la prueba es \(1 - \beta\): la probabilidad de detectar un efecto cuando de verdad lo hay.
NotaInterpretación

Una analogía útil es un juicio. \(H_0\) es “la persona es inocente”. El error tipo I es condenar a un inocente; el tipo II, absolver a un culpable. Bajar \(\alpha\) (exigir más evidencia para condenar) reduce el primero pero aumenta el segundo: los dos errores se compensan entre sí.

Lo único que reduce ambos a la vez es aumentar el tamaño de muestra, que es como conseguir más pruebas antes de juzgar. Por eso el tamaño de muestra debe planearse antes de recolectar: un estudio con muestra insuficiente tiene poca potencia y puede no detectar un efecto real.

Y aquí está el vínculo con lo dicho antes. Cuando no rechazamos \(H_0\), no sabemos si es porque no hay efecto o porque nos faltó potencia. Ese es exactamente el error tipo II, y es la razón de que no digamos “aceptamos \(H_0\)”.

En R, la potencia de una prueba para una media se calcula así:

# ¿Qué potencia tiene detectar una diferencia de 0.5 desviaciones con n = 30?
power.t.test(n = 30, delta = 0.5, sd = 1, sig.level = 0.05, type = "one.sample")
#> 
#>      One-sample t test power calculation 
#> 
#>               n = 30
#>           delta = 0.5
#>              sd = 1
#>       sig.level = 0.05
#>           power = 0.7539627
#>     alternative = two.sided

8.6 Prueba de hipótesis para una media

Preguntemos si la temperatura media de las lagartijas urbanas difiere de 34 °C, un valor de referencia:

  • \(H_0: \mu = 34\)
  • \(H_1: \mu \neq 34\) (prueba de dos colas)
t.test(urbanas$temp_corporal, mu = 34)
#> 
#>  One Sample t-test
#> 
#> data:  urbanas$temp_corporal
#> t = 4.9134, df = 31, p-value = 2.752e-05
#> alternative hypothesis: true mean is not equal to 34
#> 95 percent confidence interval:
#>  34.82984 36.00766
#> sample estimates:
#> mean of x 
#>  35.41875

La salida trae todo: el estadístico t, los grados de libertad, el valor p y, de regalo, el intervalo de confianza. El valor p resulta minúsculo, así que rechazamos \(H_0\).

8.6.1 El mismo cálculo a mano

Conviene hacer una vez con lápiz y papel lo que R acaba de hacer, para ver que no hay magia. Tomemos solo las ocho primeras lagartijas urbanas:

\[34.0,\; 36.4,\; 36.3,\; 34.1,\; 37.3,\; 35.8,\; 36.1,\; 34.4\]

Paso 1. La media. \(\displaystyle \bar{x} = \frac{\sum x_i}{n} = \frac{284.4}{8} = 35.55\)

Paso 2. La desviación estándar, con la fórmula de cálculo directo:

\[s^2 = \frac{1}{n-1}\left[\sum x_i^2 - n\bar{x}^2\right] = \frac{10120.96 - 8(35.55)^2}{7} = 1.5057\]

de donde \(s = \sqrt{1.5057} = 1.2271\).

Paso 3. El error estándar. \(\displaystyle \frac{s}{\sqrt{n}} = \frac{1.2271}{\sqrt{8}} = 0.4338\)

Paso 4. El estadístico. Aquí está la idea central, y vale la pena leerla despacio:

\[t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}} = \frac{35.55 - 34}{0.4338} = 3.573\]

Paso 5. La decisión. Con \(n - 1 = 7\) grados de libertad, el valor crítico bilateral al 5 % es \(t_{0.975,\,7} = 2.365\). Como \(3.573 > 2.365\), se rechaza \(H_0\).

Comprobación con R sobre esos mismos ocho datos:

ocho <- head(urbanas$temp_corporal, 8)
t.test(ocho, mu = 34)
#> 
#>  One Sample t-test
#> 
#> data:  ocho
#> t = 3.5728, df = 7, p-value = 0.009063
#> alternative hypothesis: true mean is not equal to 34
#> 95 percent confidence interval:
#>  34.52414 36.57586
#> sample estimates:
#> mean of x 
#>     35.55
NotaInterpretación

Los números coinciden: \(t = 3.573\), 7 grados de libertad, \(p \approx 0.009\) y un intervalo de aproximadamente \((34.52,\ 36.58)\).

Pero lo que importa no es la coincidencia, sino leer la fórmula. El estadístico \(t\) es un cociente entre la señal (qué tan lejos está la media muestral del valor de referencia) y el ruido (el error estándar). Eso explica de un vistazo tres cosas que ya sabíamos por separado:

  • Si la diferencia crece, \(t\) crece: más señal.
  • Si los datos son más dispersos, \(s\) crece y \(t\) se encoge: más ruido.
  • Si \(n\) crece, el error estándar \(s/\sqrt{n}\) se encoge y \(t\) crece: por eso con muestras grandes hasta diferencias triviales resultan significativas.

Los tres fenómenos son la misma fórmula vista desde distintos ángulos. Ese es el motivo para calcularlo a mano una vez.

Volviendo a la muestra completa:

NotaInterpretación

Redacción para un lector no técnico: “La temperatura corporal media de las lagartijas urbanas (35.4 °C) es significativamente mayor que el valor de referencia de 34 °C (\(p < 0.001\)); con 95 % de confianza, la media real está entre los límites que reporta el intervalo.”

Obsérvese que intervalo y prueba dan la misma información: como el 34 queda fuera del intervalo de confianza del 95 %, sabíamos de antemano que la prueba a \(\alpha = 0.05\) iba a rechazar. Son dos caras de la misma moneda; el intervalo suele ser más informativo porque además dice cuánto vale el parámetro.

8.6.2 Laboratorio: qué es realmente el valor p

La curva es la distribución del estadístico suponiendo que \(H_0\) es cierta. Al mover la media observada de la muestra se observa cómo el área sombreada (el valor p) se encoge conforme el resultado se aleja de lo que \(H_0\) predice.

viewof obs = Inputs.range([-4, 4], {value: 1.2, step: 0.05, label: "estadístico observado"})
viewof alfa = Inputs.select([0.10, 0.05, 0.01], {value: 0.05, label: "nivel α"})
viewof colas = Inputs.radio(["dos colas", "una cola"], {value: "dos colas", label: "tipo de prueba"})
dnorm2 = (x) => Math.exp(-0.5 * x * x) / Math.sqrt(2 * Math.PI)
erf = (x) => {
  const s = x < 0 ? -1 : 1; x = Math.abs(x);
  const t = 1 / (1 + 0.3275911 * x);
  const y = 1 - ((((1.061405429 * t - 1.453152027) * t + 1.421413741) * t
            - 0.284496736) * t + 0.254829592) * t * Math.exp(-x * x);
  return s * y;
}
pnorm2 = (x) => 0.5 * (1 + erf(x / Math.SQRT2))
valorP = colas === "dos colas" ? 2 * (1 - pnorm2(Math.abs(obs))) : 1 - pnorm2(obs)
rejilla = d3.range(-4.5, 4.51, 0.02)
cola = colas === "dos colas"
  ? rejilla.filter(x => Math.abs(x) >= Math.abs(obs))
  : rejilla.filter(x => x >= obs)
Plot.plot({
  height: 250,
  x: { label: "valor del estadístico si H₀ fuera cierta", domain: [-4.5, 4.5] },
  y: { label: "densidad" },
  marks: [
    Plot.areaY(cola, { x: d => d, y: dnorm2, fill: "#C0392B", fillOpacity: 0.28 }),
    Plot.lineY(rejilla, { x: d => d, y: dnorm2, stroke: "#1F4E79", strokeWidth: 2 }),
    Plot.ruleX([obs], { stroke: "#C0392B", strokeWidth: 2 }),
    Plot.ruleY([0])
  ]
})
md`Valor p = **${valorP.toFixed(4)}** · Decisión con α = ${alfa}: **${valorP < alfa ? "se rechaza H₀" : "no se rechaza H₀"}**`
ImportanteLas tres lecturas equivocadas del valor p

El valor p es la probabilidad de observar datos tan extremos como los nuestros si \(H_0\) fuera cierta. En cambio, no es:

  1. La probabilidad de que \(H_0\) sea cierta. El cálculo supone \(H_0\); no puede a la vez medir su probabilidad.
  2. La probabilidad de haberse equivocado al rechazar.
  3. Una medida del tamaño del efecto. Un p diminuto puede corresponder a un efecto trivial si la muestra es enorme (el tema de la siguiente sección).

8.7 Usos y abusos de la inferencia

8.7.1 Significancia estadística no es relevancia práctica

Con una muestra suficientemente grande, cualquier diferencia por minúscula que sea se vuelve estadísticamente significativa. Que un medicamento baje la presión 0.3 mmHg puede tener \(p < 0.001\) y no servirle a nadie.

set.seed(2026)
# Diferencia real ridícula (0.05) pero muestra enorme
grande <- rnorm(50000, mean = 100.05, sd = 15)
t.test(grande, mu = 100)$p.value
#> [1] 0.1877995

Por eso hay que reportar siempre el tamaño del efecto y su intervalo de confianza, no solo el valor p. La pregunta no es “¿es significativo?”, sino “¿es lo bastante grande como para importar?”.

8.7.2 El p-hacking

Si uno prueba muchas hipótesis, algunas saldrán “significativas” por puro azar. Con \(\alpha = 0.05\), una de cada veinte pruebas sobre datos sin ningún efecto real dará \(p < 0.05\):

set.seed(2026)
# 20 pruebas sobre datos SIN ningún efecto real
p_valores <- replicate(20, t.test(rnorm(30), mu = 0)$p.value)
round(p_valores, 3)
#>  [1] 0.720 0.305 0.865 0.265 0.114 0.831 0.384 0.579 0.336 0.503 0.819 0.564
#> [13] 0.548 0.925 0.902 0.209 0.378 0.599 0.550 0.222
sum(p_valores < 0.05)   # casi siempre sale alguna "significativa"
#> [1] 0

Buscar entre muchos análisis hasta encontrar uno significativo, y reportar solo ese, se llama p-hacking, y es una de las causas de la crisis de replicabilidad en varias ciencias. La defensa: decidir las hipótesis antes de ver los datos, reportar todos los análisis realizados y ajustar por comparaciones múltiples (lo veremos con las pruebas post-hoc en el Capítulo 11).

Tip¿Qué técnica usar?

Con una muestra y un parámetro:

Mi pregunta Herramienta
¿Cuánto vale \(\mu\), con margen de error? Intervalo de confianza para la media
¿Es \(\mu\) compatible con un valor de referencia? Prueba de hipótesis para una media (t.test(x, mu = ...))
¿Cuál de las dos reporto? Idealmente ambas: la prueba decide, el intervalo cuantifica

Supuestos: muestra aleatoria y, o bien población aproximadamente normal, o bien \(n\) suficientemente grande para que aplique el TCL. Verifícalos con un boxplot y un Q-Q plot (Capítulo 2) antes de confiar en el resultado.

8.8 Resumen

La estimación puntual da un número; el intervalo de confianza le agrega la incertidumbre, y su nivel describe la tasa de acierto del procedimiento, no la probabilidad de un intervalo concreto. La prueba de hipótesis supone \(H_0\), mide qué tan raros serían nuestros datos bajo ese supuesto (el valor p) y decide. Un valor p pequeño indica incompatibilidad con \(H_0\), pero no dice qué tan grande es el efecto ni qué probabilidad tiene \(H_0\) de ser cierta. Con muestras grandes, lo trivial se vuelve significativo; con muchas pruebas, el azar fabrica significancia. Por eso el buen análisis reporta efecto, intervalo y contexto, no solo un p. En el Capítulo 9 llevaremos estas ideas a la comparación de dos grupos.

  3. Interpretación correcta. ¿Cuáles de estas afirmaciones sobre un IC del 95 % \((34.1,\ 34.7)\) son correctas?

    1. Hay 95 % de probabilidad de que \(\mu\) esté entre 34.1 y 34.7.
    2. El 95 % de los datos están entre 34.1 y 34.7.

  8. Tipos de error. Se contrasta \(H_0: \mu = 3\) contra \(H_1: \mu > 3\), y se decide rechazar \(H_0\) cuando la media muestral supera 3.4. En ese contexto, ¿cuál de las siguientes describe el error tipo II?

TipSoluciones y retroalimentación

1. Con t.test(filter(lagartijas, habitat == "campo")$temp_corporal)$conf.int se obtiene un intervalo alrededor de 34 °C. Interpretación correcta: “Con 95 % de confianza, la temperatura corporal media de las lagartijas de campo abierto está entre los dos límites del intervalo”, entendiendo que el 95 % se refiere a la tasa de acierto del procedimiento. Conviene evitar la redacción “hay 95 % de probabilidad de que la media esté en este intervalo”.

2. El del 99 % es el más ancho y el del 90 % el más angosto. Tiene sentido: para estar más seguros de atrapar el parámetro hay que lanzar una red más grande. Existe un intercambio inevitable entre confianza y precisión; la única forma de mejorar ambas a la vez es aumentar \(n\), como se ve en el laboratorio del Sección 8.2.1.

3. Solo la (c) es correcta. La (a) es la interpretación equivocada más común: una vez calculado, el intervalo ya contiene o no contiene a \(\mu\); la probabilidad describe al método. La (b) confunde el intervalo de confianza —que habla de la media— con la dispersión de los datos individuales; un IC es mucho más angosto que el rango de los datos. Distinguir (b) de un intervalo de predicción es una confusión sutil que vale la pena señalar en clase.

4. \(H_0: \mu = 10\) contra \(H_1: \mu \neq 10\). Con t.test(filter(ab, entorno == "Mac")$tiempo_ms, mu = 10) se obtiene una media muestral cercana a 10.6 ms y un valor p de alrededor de 0.02, así que a \(\alpha = 0.05\) se rechaza \(H_0\): el tiempo medio de Mac difiere significativamente de 10 ms. Nótese que este caso es mucho menos contundente que el de las lagartijas (\(p < 0.001\)). Un p de 0.02 es evidencia moderada, y conviene decirlo así en vez de tratar todo lo menor que 0.05 como un sí rotundo. Reportar también el intervalo (aproximadamente de 10.1 a 11.1 ms): informa cuánto vale la media, no solo que difiere.

5. Las incorrectas son la (a) y la (c). La (a) invierte el condicional: el valor p se calcula suponiendo \(H_0\) cierta, así que no puede ser la probabilidad de \(H_0\). La (c) confunde significancia con magnitud: el valor p depende tanto del tamaño del efecto como del tamaño de muestra. La (b) es la lectura correcta. La confusión (a) tiene nombre: falacia del condicional transpuesto, y es el error más frecuente al leer resultados científicos en prensa.

6. Probablemente no solo por ese resultado. El efecto es de 0.05 puntos porcentuales: estadísticamente significativo gracias a los 200 000 usuarios, pero práctica y económicamente irrelevante en casi cualquier contexto. Información adicional que pediría: el intervalo de confianza de la diferencia (para saber si el efecto podría ser aún menor), el costo de implementar el cambio, si hay efectos secundarios en otras métricas, y si el experimento fue una prueba A/B bien aleatorizada. Este es el ejemplo canónico de por qué reportar solo el valor p es insuficiente. Significancia y relevancia son preguntas distintas.

7. Con 200 pruebas sobre datos sin efecto real, lo esperado es que alrededor de 10 resulten significativas (\(200 \times 0.05\)). El número exacto varía por azar, típicamente entre 5 y 16. La moraleja: si alguien corre 200 análisis y reporta solo los 10 “hallazgos”, está describiendo ruido con lenguaje de descubrimiento. Por eso importa preregistrar las hipótesis y reportar cuántas pruebas se hicieron en total.

8. La respuesta es la (b): no rechazar \(H_0\) cuando en realidad \(\mu > 3\). El error tipo II consiste en no detectar un efecto que sí existe, es decir, quedarse con la hipótesis nula siendo falsa. La opción (a) describe el error tipo I; las opciones (c) y (d) describen decisiones correctas. Truco para no confundirlos: el tipo I se comete al rechazar (falso positivo) y el tipo II al no rechazar (falso negativo). Basta con fijarse en qué decisión se tomó y compararla con la realidad.

9. (a) \(H_0: p = 0.12\) contra \(H_1: p < 0.12\), unilateral izquierda: la afirmación es que produce menos efectos. (b) \(H_0: \mu = 80\) contra \(H_1: \mu \neq 80\), bilateral: interesa cualquier desviación del valor nominal. (c) \(H_0: \mu = 8000\) contra \(H_1: \mu > 8000\), unilateral derecha. Nótese que la hipótesis nula siempre lleva la igualdad, y que la dirección de \(H_1\) la dicta la pregunta —no los datos—.

10. Le conviene \(\alpha = 0.05\). Un nivel de significancia más alto hace más fácil rechazar \(H_0\) y, por tanto, más probable obtener evidencia a favor de su afirmación. El riesgo que asume es un mayor error tipo I: cinco de cada cien veces declararía un efecto inexistente, contra una de cada cien con \(\alpha = 0.01\). Vale la pena discutir la tensión ética. Quien tiene interés comercial en el resultado prefiere el umbral laxo, y por eso los niveles se fijan por convención de la disciplina y no los elige quien financia el estudio. En contextos donde un falso positivo es costoso (aprobar un fármaco inseguro) se usa \(\alpha = 0.01\) o menor.

11. Con power.t.test(n = 30, delta = 0.5, sd = 1, type = "one.sample") la potencia es aproximadamente 0.75; con \(n = 100\) supera 0.99. Para una potencia de 0.90 se necesitan alrededor de 44 observaciones, que se obtienen con power.t.test(power = 0.90, delta = 0.5, sd = 1, type = "one.sample"). Esta función es la herramienta para planear el tamaño de muestra antes de recolectar datos: se fija el efecto mínimo que interesa detectar y la potencia deseada, y devuelve la \(n\) necesaria. Hacerlo al revés —recolectar primero y calcular la potencia después— no sirve de nada.
