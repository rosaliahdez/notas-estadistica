A.2 Ejercicio guiado: medidas de resumen

Calcular la media, la mediana y la desviación estándar del vector temperaturas.

Las funciones se llaman mean(), median() y sd(). Cada una recibe el vector como argumento, por ejemplo mean(temperaturas).

temperaturas <- c(35.1, 34.8, 36.2, 35.9, 33.7, 35.4, 34.2)

mean(temperaturas)
median(temperaturas)
sd(temperaturas)

La media y la mediana resultan muy parecidas, señal de una distribución bastante simétrica. La desviación estándar indica cuánto se apartan las temperaturas de su promedio, en grados.

A.3 Ejercicio guiado: una prueba de hipótesis

Las siguientes son temperaturas de una muestra de lagartijas urbanas. Probar si su media difiere de 34 °C con t.test(), e interpretar el valor p.

El primer argumento es el vector de datos (urbanas) y mu es el valor de referencia bajo la hipótesis nula, en este caso 34.

urbanas <- c(35.1, 36.4, 36.3, 34.9, 35.8, 34.2, 37.1, 35.5,
             36.0, 34.6, 35.9, 36.8, 34.4, 35.2, 36.6)

t.test(urbanas, mu = 34)

El valor p resulta muy pequeño, así que se rechaza \(H_0\): la temperatura media de estas lagartijas difiere significativamente de 34 °C. Conviene observar también el intervalo de confianza que reporta la salida: no contiene al 34, lo cual es coherente con haber rechazado. La interpretación completa está en el Capítulo 8.

A.4 Ejercicio guiado: comparar dos grupos

Comparar las temperaturas de lagartijas urbanas y de campo. ¿Difieren sus medias?

Con dos vectores separados, la prueba se escribe t.test(grupo1, grupo2). Antes de ejecutarla conviene mirar los datos con boxplot(urbana, campo).

urbana <- c(35.1, 36.4, 36.3, 34.9, 35.8, 34.2, 37.1, 35.5, 36.0, 34.6)
campo  <- c(33.8, 34.2, 33.1, 34.9, 33.5, 32.9, 34.4, 33.7, 34.0, 33.2)

boxplot(urbana, campo, names = c("urbana", "campo"),
        ylab = "Temperatura (°C)")

t.test(urbana, campo)

Las cajas están claramente separadas y el valor p es muy pequeño. Las lagartijas urbanas son significativamente más cálidas. Como se vio en el Capítulo 9, reportar el intervalo de la diferencia es más informativo que reportar solo el valor p.
