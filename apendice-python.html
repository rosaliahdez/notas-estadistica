R y Python, lado a lado

El curso usa R, pero muchos estudiantes de la licenciatura llegan con más experiencia en Python. Este apéndice pone las dos versiones del mismo cálculo una junto a la otra.

NotaPara qué sirve esta tabla

No para trabajar en Python durante el curso (las prácticas y el proyecto se entregan en R), sino para que quien ya conoce Python reconozca lo que está viendo y para que quede claro que las técnicas son las mismas: lo que cambia es la sintaxis.

En Python los equivalentes viven en tres bibliotecas: pandas para manipular datos, scipy.stats para las pruebas y statsmodels para modelos.

Nota sobre los cuartiles: el curso usa la convención de la posición \((n+1)p\), que en R se pide con type = 6. El valor por omisión de R y el de pandas usan la otra convención, así que sus \(q_1\) y \(q_3\) difieren un poco. | Tabla de frecuencias | table(g) | g.value_counts() | | Tabla de contingencia | table(a, b) | pd.crosstab(a, b) | | Resumen por grupo | group_by(g) \|> summarise(...) | datos.groupby("g").agg(...) | | Correlación | cor(x, y) | x.corr(y) | | Matriz de correlación | cor(df) | df.corr() |

Nótese una diferencia de estilo: en R las funciones reciben el objeto (mean(x)), y en Python el objeto lleva el método (x.mean()). Es la distinción entre programación funcional y orientada a objetos, y explica casi toda la diferencia visual entre ambos lenguajes.

Un ejemplo completo, en los dos lenguajes

La misma pregunta (¿difiere el agrado entre las marcas de galletas?) resuelta de las dos formas:

  • R
  • Python
library(tidyverse)
galletas <- read.csv("datos/galletas.csv")

# descripción
galletas |>
  group_by(marca) |>
  summarise(n = n(), media = mean(agrado), de = sd(agrado))

# ANOVA y post-hoc
modelo <- aov(agrado ~ marca, data = galletas)
summary(modelo)
TukeyHSD(modelo)

# supuestos
shapiro.test(residuals(modelo))
bartlett.test(agrado ~ marca, data = galletas)
import pandas as pd
from scipy import stats
import statsmodels.api as sm
import statsmodels.formula.api as smf
from statsmodels.stats.multicomp import pairwise_tukeyhsd

galletas = pd.read_csv("datos/galletas.csv")

# descripción
print(galletas.groupby("marca")["agrado"].agg(["count", "mean", "std"]))

# ANOVA y post-hoc
modelo = smf.ols("agrado ~ C(marca)", data=galletas).fit()
print(sm.stats.anova_lm(modelo, typ=2))
print(pairwise_tukeyhsd(galletas.agrado, galletas.marca))

# supuestos
print(stats.shapiro(modelo.resid))
grupos = [g["agrado"].values for _, g in galletas.groupby("marca")]
print(stats.bartlett(*grupos))
TipLa conclusión de fondo

Los dos bloques hacen exactamente lo mismo y dan exactamente los mismos números. La estadística no cambia con el lenguaje.

Lo que se aprende en este curso (qué técnica corresponde, qué supuestos verificar, cómo interpretar el resultado) es transferible a cualquier herramienta. La sintaxis se consulta; el criterio, no.
